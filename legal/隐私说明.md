# 隐私说明

版本：v2-20261112（与程序内 `CONSENT_VERSION` 同源）
生效日期：2026 年 11 月 12 日
运营方：X.H 团队　联系邮箱：dreamarchitect1026@gmail.com

本说明按六个问题逐条说明。除本说明明确列出的情形外，本应用不向任何服务器传输数据。

## 1. 我们收集什么

1.1 设备数据：端口电压、电流、功率、温度、充电状态、协议版本与错误计数。这些数据由本机通过 USB/IP 或蓝牙读取。
1.2 使用记录：端口开关时间、自动关闭触发与失败记录、会话时长。
1.3 用户输入：你在 AI 分析中的提问，以及你勾选允许发送的数据范围。
1.4 配置信息：界面偏好、端口命名、AI 端点与模型名、是否脱敏。

**我们不收集**：姓名、手机号、身份证号、住址、精确位置、通讯录、短信、相册、剪贴板、麦克风、摄像头、生物识别信息，也不收集与本应用功能无关的任何文件内容。

## 2. 为什么收集

2.1 设备数据与使用记录用于展示状态、绘制曲线、生成统计与执行自动关闭策略，全部在本机完成。
2.2 用户输入仅在你主动发起 AI 分析时使用。
2.3 配置信息用于记住你的设置。

## 3. 存在哪里

3.1 数据目录：`%LOCALAPPDATA%\CuktechPanel\`。其中：
- `data\`：历史数据库（SQLite）与运行态；
- `runtime.json`：本机回环接口的一次性令牌（`X-Local-Token`）；
- `crash.log`：崩溃与异常栈；`errs.json`：异常台账（种类、次数、首次站点）；
- `auto_off.log`：自动关闭审计（时间、端口、阈值、是否跳过）。
3.2 配置与同意状态：`HKEY_CURRENT_USER\Software\DoubaoWork\CuktechPanel`（含 `legal/accepted`、`legal/accepted_at`）。
3.3 AI 密钥：使用 Windows DPAPI（当前用户）加密后保存在上述配置中；DPAPI 不可用时退化为加盐混淆并在界面标记。密钥不写入日志、不进入源码。

## 4. 存多久

4.1 `crash.log`：单文件超过 8 MB 轮转为 `.1.gz`，最多保留 5 份归档。
4.2 `errs.json`：单文件，覆盖写入，保留最近一次运行台账。
4.3 `auto_off.log`：逐行追加，应用不自动清理。
4.4 历史数据库：长期保留，直到你在应用内删除或手动删除数据目录。
4.5 卸载程序不会删除 `%LOCALAPPDATA%\CuktechPanel` 数据目录，也不会删除该注册表项下的其它配置；但**会删除协议同意记录**（`legal/accepted`、`legal/accepted_at`），重装后需重新确认一次。如需彻底清除全部数据，请按第 6 节操作。

## 5. 是否给第三方（谁、什么字段）

5.1 除你主动开启的 AI 分析和 MQTT 集成外，本应用不主动发起外网连接；本机回环接口只监听 `127.0.0.1:8080`。

5.2 **MQTT 集成（默认关闭）**：只有你在「设置 → 连接设置」里打开 MQTT 并保存地址后，本应用才会主动连接你填写的 broker（例如巴法云，地址 `bemfa.com`、端口 9501；此时客户端 ID 填巴法云私钥 UID，用户名/密码留空）。连接使用**明文 TCP、无 TLS**；发送的内容是设备状态（端口开关、电压、电流、功率、充电事件、设置项），并接收该地址下发的端口开关与参数指令。地址不是本机时，**这些数据会离开这台电脑**，且我们（X.H 团队）不参与、不经手、不存储。关闭该开关即停止连接与外发。

5.3 **AI 分析的数据流向**：只有你打开"启用 AI 分析"后，本应用才会外发内容。默认端点为 `https://api.deepseek.com`（模型 `deepseek-chat`），也就是说，你一旦启用 AI 分析，你的提问就会发送给深度求索公司这一第三方，由该公司按其隐私政策处理。发送的内容是：你的提问文本，以及脱敏后的聚合特征（默认开启脱敏，不发送原始曲线、端口明细与设备标识）。**已发送的内容无法从该第三方撤回。**你的 API Key 仅保存在本机，经 Windows DPAPI（当前用户）加密，不写入日志。你可以把端点改为本机地址（如 `http://127.0.0.1:1234/v1` 的 LM Studio/Ollama），此时数据不出本机。
5.4 发送的技术细节：请求路径为 `/chat/completions`，请求头携带你的 API Key，请求体字段为 `model`、`messages`（系统提示词 + 你的问题 + 你许可的数据）、`temperature`、`max_tokens`（流式时另有 `stream`）。脱敏开启时只发送聚合特征（时长、总量、峰值、异常计数），不发送原始高频曲线、端口原始明细、设备 MAC 与序列号、诊断日志原文；关闭脱敏后发送的字段为：`id`、`port`、`start_time`、`end_time`、`total_wh`、`avg_power_w`、`peak_power_w`、`avg_voltage`、`avg_current`、`duration_sec`、`protocol`、`total`、`is_active`（会话行，无设备标识；不含端口逐项开关与功率）。
5.5 我们（X.H 团队）不运营任何接收用户数据的服务器，不接收、不存储、不转售上述数据；MQTT 只连你填写的地址。

## 6. 怎么查阅、导出、删除、撤回

6.1 查阅：应用内"设置"可查看全部配置；"隐私与日志"页展示 AI 实际发送字段清单。
6.2 导出：设置中可导出诊断台账（异常种类/次数/站点）与通知留痕；历史数据库为本地 SQLite 文件，可自行复制。
6.3 删除：关闭应用后删除 `%LOCALAPPDATA%\CuktechPanel\` 整个目录，并删除注册表项 `HKEY_CURRENT_USER\Software\DoubaoWork\CuktechPanel`。**卸载程序不会删除上述数据目录与注册表项下的其它配置**：卸载只移除程序文件、开始菜单快捷方式与卸载登记，并删除协议同意记录 `legal/accepted` 与 `legal/accepted_at`；其余数据与配置需按本条手动删除。
6.4 撤回同意：关闭"启用 AI 分析"开关即停止一切外发；如需清除同意记录，删除上述注册表项中的 `legal/accepted` 与 `legal/accepted_at`。撤回后离线功能（端口控制、状态查看、历史与自动关闭）仍可正常使用。
6.5 卸载：卸载程序会删除程序目录、开始菜单快捷方式与卸载注册表项，并清除协议同意记录（`legal/accepted`、`legal/accepted_at`，重装后需重新确认），但保留用户数据目录与其余配置（见 4.5）。
