# 更新记录

本文件按版本倒序记录对外可见的变化。构建批次与内部验收数据不放这里，见仓库内出包记录。

## 2.1.1 — 2026-11-17

**协议识别（展示与可选约束）**

- 充电记录列表新增「协议」列：短码 + 悬停全称，占用右侧富余宽度，既有列宽不变；记录明细同步显示协议全称。
- 设备分组待选行在六列之后追加协议短码；组卡片第三行显示「主协议 + 占比」（如「主协议 PD 3.0 62%」）。
- 维度约束新增可选「协议」维度：勾选并填写短码后才过滤，不预置、默认不生效；协议不参与训练、不进入特征向量。

**模型口径**

- 撤回协议类别 one-hot 与 unknown 位，特征回到纯数值口径（114 维）；随包模型 `ck2026.11-r07-v1` 用同批数据、同划分重训。
- 同批对比：含协议 121 维与纯数值 114 维的测试集准确率持平（0.4878 vs 0.4878），macro-F1 0.3863 → 0.3903，协议未带来增益，故不保留。

**界面与稳定性**

- 最小默认尺寸（995×760）下分组摘要改为三行并按「；」折行，长备注不再出现省略号。
- 重复打开「管理分组」不再叠加二级页；从侧栏切走时清理分组页，修复页面泄漏。

## 2.1.0 — 2026-11-17

**分组与学习**

- 「重新分组」语义重做：主体改为「未归箱 + 非固定组」；固定组只允许新增成员，名称与已有成员一条不改；非固定组可并入固定组、并入其它非固定组或新建。
- 新增「偏离项」与「无法判定」两个隔离桶：明显偏离固定组特征的记录单独隔离，判不了的统一归位，不再散落在未归箱。
- 重新分组结束立即落库并重训，界面摘要给出固定组变动条数、新建组数、隔离条数与训练前后置信度。
- 维度约束不再默认：初始化、重新分组、升级迁移三处都不再写回预置约束；「恢复自动」或取消全部勾选可真正清空，清空后该组不再按区间判定。升级时只清理「系统预置且用户没改过」的值，手设值保留。

**AI 与交互**

- AI 复核支持「一键采纳 / 采纳所选」，采纳后强制从磁盘重读模型并落库，可在各组条数中看到变化；修复此前只提示不生效的断链。
- 「当前分组」列表点选、切换、刷新保持原滚动位置，滚轮照常可用。
- 充电记录页动作区去掉「按曲线聚类」，小字拆两行、左对齐、行距统一。
- 「按曲线看分箱」入口保留在设备分组页顶部；修复删除按钮时连带丢失的预览入口。

**曲线与界面**

- 修复状态页曲线空白：主图在建图门槛只认端口控制页，默认停在状态页时图表从未创建；改为状态页或端口页首次可见即建图。
- 修复挂起/恢复后曲线为空：挂起期间持续采样，恢复时重取基底补画。
- 端口控制四卡常驻近 3 分钟曲线，空载保留网格占位；同档位卡片等高。
- 最小默认窗口尺寸（995×760）逐页复核：设备分组页摘要改两行渲染，长备注不再出现省略号；其余页面无重叠、裁切与多余滚动条。

**文档与许可**

- 新增图文 README、功能说明、架构说明、安装与配置、FAQ、更新记录、许可证与第三方组件清单。

## 1.5.9 — 2026-11-16

- 智能分析「设备识别」卡改卡内滚动，视口锁 5 行，0 条时清空但几何不变。
- 底部动作区改为单行四按钮，删除「充电日报」入口；断开原因超过 7 类合并为「其他 N 类」。
- 设备分组页两行操作改 5 列栅格，标题显示「当前分组 N」，上限徽标「上限 12 · 已用 N」。
- 分箱卡重排：标题、缩略图、星标左缘对齐，标题两行不省略；滚动区加圆角边框；组内会话按页均分行高。
- 连接设置两卡按最高模式锁高，新增「快速接入」四步说明卡（蓝牙地址 / 巴法云）。
- 模式与显示页：USB-A 小电流并入「设备设置」，统一分段选择器，四卡均分余量。
- 说明点改为悬停约 3 秒浮出，界面不再常驻问号；进阶配置底部只留三个按钮。
- 新增《功能说明》，按 13 个模块逐条说明。

## 1.5.8 — 2026-11-16

- 品牌统一「星源智控」：界面、文档、许可与预置分组名一致；可执行文件名、安装目录、数据目录与协议字段保持不变。
- 分箱列表改单列滚动容器，自带滚轮与绘制式指示条，刷新保持位置。
- 「重新分组」收敛为单入口，增加固定组快照校验与审计。
- 会话明细补充均压、均流、峰均比、常用口与时段。
- 设置页新增「无充电关端口延时（分钟）」，范围 1–1440，默认 10，保存即生效。
- 设备分组上限默认 12（范围 3–30），新建组默认非固定。

## 1.5.7 — 2026-11-15

- 修复分组合并语义：成员逐条钉入保留组，合并前后条数守恒；撤销只摘除本次新钉入的成员。
- 合并确认框列出来源与冲突处理，合并后只读校验；撤销后回显恢复条数。
- 新增合并自检入口，用于验证守恒与撤销对称。

## 1.5.6 — 2026-11-15

- 修复启动时无条件重写「星源智控」开始菜单快捷方式的问题：仅在快捷方式缺失或目标失效时写入，避免开发实例抢占安装版入口。
- 新增公开的距离计算封装，消除对私有符号的跨模块访问。

## 1.5.5 — 2026-11-15

- 状态行新增巴法云 MQTT 徽章，与设置页同源；连接状态只显示短状态词，地址与失败原因移入悬停提示。
- 统一六条快捷方式目标为安装版程序，清理遗留脚本参数。
- 隐私说明、用户协议与第三方许可随安装包发布。
