# 2.1.1 出包记录

- 版本：**2.1.1**
- 日期：2026-11-17
- 类型：功能版（协议展示 + 可选约束；模型口径修正）
- 结论：构建、打包、静默安装、快捷方式重链、六项自检与实窗验收全部通过

## 一、本版改了什么、为什么、验证结论

| 改动 | 为什么 | 验证结论 |
|---|---|---|
| 待选栏、组内会话行、组卡片增加协议 | 协议是人工判断归属的直接线索，原界面看不到 | 待选栏末列显示短码；窄窗两行行式首行含协议；卡片第三行显示「主协议 + 占比」；995 实窗无省略、无横向滚动 |
| 充电记录列表增加「协议」列，明细页显示全称 | 记录页原先没有协议，回查要进明细 | 8 列在 995 下完整显示，协议列 56 px 取自原富余宽度，已有列未变窄，行高一致 |
| 协议作为可选约束维度（默认不勾选） | 用户需要时可按协议过滤候选，不需要时不干扰 | 弹窗含「协议」行，默认未勾选、数值/徽标与其他维度一致；勾选 `PD,PPS` 时大小写均命中，取消勾选后不参与过滤 |
| 协议从模型特征中撤回 | 同批消融显示协议无增益，且协议属类别型线索，不适合作为数值特征硬编码 | 特征由 121 维回到 114 维纯数值；同批同划分准确率 0.4878 vs 0.4878、macro-F1 0.3863→0.3903，测试集 41 条预测变化 0 条 |
| 模型重训并导出 | 与撤回后的特征口径保持一致 | 随包模型版本 `ck2026.11-r07-v1`，arch=logistic，114 项特征名与推理侧逐项对齐 |
| 分组页窄窗版式修正 | 995 宽度下七字段单行必然省略 | 窄窗两行行式（字号不变），宽窗（≥1180）回单行；行高、分页、列表高度随模式切换 |
| 分组摘要与页面泄漏修复 | 摘要在窄窗折行溢出；切换页面重复建页 | 摘要三行并按「；」折行；离开分组页即清理、打开前去重，控件树仅一页 |
| AI 数据白名单补 `period` | 会话统计带「今日/近 7 天」时会被白名单拒绝 | 复测构造请求通过，不再出现「未登记字段」拒绝 |

## 二、消暗疾与代码自检

- 逐项复核：状态同步、跨页刷新、启动回读、空态占位、空值与异常分支、线程与 UI 交互、越界与命中区、定时器编排、构建脚本残留、日志刷屏。
