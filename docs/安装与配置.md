# 安装与配置

版本：2.1.1　适用：Windows 10 / 11（64 位）

## 1. 安装

### 1.1 安装版

1. 双击安装包，按向导下一步完成安装。
2. 默认安装到当前用户目录，不需要管理员权限；可选创建桌面快捷方式。
3. 安装完成后从开始菜单或桌面「星源智控」启动。

静默安装（供批量部署）：

```
CuktechPanel-2.1.1-setup-win64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /TASKS="desktopicon"
```

### 1.2 便携版

1. 解压整个目录到任意位置（U 盘、桌面均可），不要只拷 exe。
2. 双击 `CuktechPanel.exe` 启动；卸载 = 删除整个目录。
3. 便携版与安装版共用同一数据目录，换机时一并拷走数据目录即可保留记录与设置。

### 1.3 覆盖升级

- 直接运行新安装包覆盖安装即可；只替换程序文件，历史库、配置与学习模型保留。
- 升级后首次启动会做一次数据兼容检查，旧分组与手设约束按原值保留。

## 2. 首次设置

1. 首次启动展示《隐私说明》与《用户协议》；不同意只停用 AI，端口控制、状态、记录与自动关闭仍可用。
2. 充电器通电，手机或电脑蓝牙保持开启。
3. 打开「设置 → 连接设置」，按「快速接入」获取充电器蓝牙地址。
4. 填入蓝牙地址、Token 与蓝牙密钥，点「连接设备」；状态显示「蓝牙 已连接」后点「保存蓝牙配置」。
5. 回到状态页确认四个端口有读数；插上设备后状态页与端口页会开始绘制曲线。

## 3. 巴法云接入（四步）

1. 注册并登录 bemfa.com，复制「私钥 UID」。
2. 在巴法云控制台新建四个主题，例如 `ck_c1`、`ck_c2`、`ck_c3`、`ck_a`，分别对应 C口1、C口2、C口3、USB-A。
3. 回到「设置 → 连接设置 → MQTT」，模式选「巴法云」，客户端 ID 填私钥 UID，用户名与密码留空。
4. 把四个主题名原样粘贴到四路输入框，点「测试连接」，成功后保存。

说明：

- 巴法云服务器为 `mqtt.bemfa.com`，明文端口 9501，TLS 端口 9503。
- 同一私钥 UID 多客户端会互踢；QoS 仅支持 0/1。
- 不接入 MQTT 时保持关闭，程序不发起外连；连接失败只影响 MQTT，不影响蓝牙与本地功能。

## 4. 常用配置位置

| 配置 | 位置 |
|---|---|
| 蓝牙地址、Token、密钥 | 设置 → 连接设置 |
| MQTT / 巴法云 | 设置 → 连接设置 → MQTT |
| 充电模式、息屏、外观 | 设置 → 模式与显示 |
| 充电时长上限、低功率保护、过温/过功率、无充电关端口 | 设置 → 充电限制与保护 |
| 服务端口、日志级别、保留天数、自启、导出 | 设置 → 服务与数据 |
| 设备灵敏度、形态阈值、分组上限、分组管理 | 设置 → 进阶配置 |
| 记录保留与清理 | 设置 → 服务与数据（保留天数） |

## 5. 数据目录

- 配置、历史库、学习模型与日志都在本机 `%LOCALAPPDATA%\CuktechPanel`。
- 覆盖安装与卸载都不会自动删除该目录。
- 需要迁移到另一台机器时，退出程序后复制整个目录；需要彻底清理时删除该目录。
- 导出的诊断包与记录包写到用户指定目录，不自动上传。

## 6. 卸载

- 安装版：开始菜单「星源智控 → 卸载 星源智控」，或系统「应用和功能」中卸载。
- 便携版：直接删除程序目录。
- 卸载后如需清除个人数据，手动删除 `%LOCALAPPDATA%\CuktechPanel`。
