# 架构说明

版本：2.1.1

本文说明程序由哪些部分组成、数据从哪里来、落到哪里、按什么顺序判定，以及学习模型的训练与版本口径。

## 1. 总体形态

- 单窗口桌面应用：左侧固定导航（状态、端口控制、充电记录、自动化、设置），底部辅助入口「小源」。
- 主进程负责界面与单实例通道；后端服务负责蓝牙采样、状态机、历史库与自动化。
- 二者只通过本机回环 HTTP 交换数据，不监听外部网卡。
- 除用户主动开启的 AI 与 MQTT 外，程序不发起外连。

## 3. 关键模块职责

### 3.1 界面层（主程序）

- 页面栈承载六个一级页与「设备分组」二级页；切换页只做取数与渲染，不改业务状态。
- 图表统一由 pyqtgraph 绘制：状态页一张合并图，端口页每卡一张小图。
- 单实例：第二次启动通过本机命名通道把命令转给已运行实例，不产生第二个窗口。
- 自检入口（隐藏参数）用于逐页冒烟、设置页适配、保护规则、合并守恒、滚动性能与 AI 分页截图。

### 3.2 业务核心

- 会话聚合：把采样点折算为时长、充入电量、峰值/均值功率、均压均流、峰均比、常用口与时段，并保留会话协议字段用于展示。
- 分组模型：固定组、普通组、特殊桶（偏离项、无法判定）与未归箱；限制分组上限。
- 学习模型：按会话数值特征向量与曲线形态做中心更新与置信度计算，支持人工样本加权；协议不编码为特征。
- 统计与建议：设备识别、断开原因分布、电压体检、单设备习惯与建议。

### 3.3 后端服务

- 蓝牙层负责连接、重连、遥测解析与开关下发；断连时按退避重试。
- 状态机按端口维护充电阶段与「已充满」判定。
- 历史层把插拔区间聚合为会话，采样点按会话归档，超期按天清理。
- 保护层把时长、低功率、过温、过功率与无充电关端口统一到一条规则链，命中即下发并记日志。

## 4. 数据落库

| 数据 | 位置 | 说明 |
|---|---|---|
| 会话与采样点 | 本地数据目录 `data/port_history.db`（SQLite） | 会话表一条对应一次插拔；采样点表按会话与时间索引；两表均含 `protocol` 列 |
| 配置 | 本机用户配置（QSettings） | 蓝牙、服务、显示、保护、分组上限等 |
| 学习模型 | 本机数据目录的模型文件 | 中心、样本计数、训练次数、留出评估 |
| 运行日志 | 本地数据目录 `logs/` | 保护触发、连接异常、服务启停 |
| 导出包 | 用户指定目录 | 诊断与记录导出，不自动上传 |

- 覆盖安装只替换程序文件，不迁移、不删除上述数据。
- 卸载不删除历史库；彻底清理需手动删除数据目录。

## 5. 判定链

会话归属按以下优先级逐级尝试，前一级给出结论即停止：

1. **人工**：用户迁移、改名、合并、AI 建议采纳产生的显式归属。
2. **形态**：曲线形态与固定组中心的距离，低于阈值即匹配。
3. **学习**：多维特征向量与各组中心的相似度，取最高且过门槛者。
4. **规则**：端口、时段、功率区间等可解释规则。
5. **约束**：仅当该组存在用户自设且启用的约束时才参与；约束为空则不进入本级。协议是可选约束维度之一，未勾选时不参与。

- 固定组只增不删：重新分组可以往固定组新增成员，但不改写名称、不删除已有成员。
- 偏离项与「无法判定」是隔离桶，不参与固定组统计；后续重新分组会重新评估，不会永久沉淀。
- 每次重新分组结束立即落库并触发训练，下一次判定使用新模型。

## 6. 模型训练与版本口径

- **样本**：人工归属权重最高；AI 采纳与重新分组产生的归属按来源记权重。
- **特征**：峰值、均值功率、电量、时长、均压、均流、时段（圆周编码）、端口、峰均比，以及曲线形态向量。2.1.1 起协议只做展示与可选约束，不进入特征向量；随包模型为纯数值口径（114 维），版本串 `ck2026.11-r07-v1`。
- **中心更新**：默认增量更新；可在「进阶配置 → 设备识别 → 中心更新策略」切换。
- **训练计数**：每次训练 `n_train` 加一；模型版本号 = `n_train ÷ 1000` 取整，因此新装显示 `v0`，累计满一千次训练进入 `v1`。
- **置信度**：按组内样本一致性计算；重新分组后界面摘要会给出训练前后置信度。
- **留出评估**：训练时保留一部分样本做留出比对，界面显示「模型 / 规则」两侧准确率，用于判断模型是否真的比规则更准。
- **可回退**：模型文件缺失或损坏时自动退回规则判定，界面不阻塞。

## 7. 性能口径

- 曲线渲染按当前窗口档位取点数；切页只重建可见图表。
- 会话列表分页读取，批量操作按批提交，避免一次性渲染全部行。
- 分组页滚动位置在点选、切换、刷新后保持；滚轮步进与滚动条同步。
- 空闲时降低图表刷新频率，有负载或切页立即恢复。
