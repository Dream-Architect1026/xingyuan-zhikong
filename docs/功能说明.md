# 功能说明

版本：2.1.1　适用：星源智控控制面板（安装版与便携版）

按模块逐条说明界面上的每项功能做什么、怎么用。界面上不常驻「?」图标：鼠标在项目上停留约 3 秒会浮出该条说明，移开即收；完整口径以本文为准。

## 1. 状态

1.1 顶部显示充电器连接状态（蓝牙 / 本地服务 / 端口就绪），异常时给出原因与重连入口。
1.2 各端口卡片显示实时功率、电压、电流与协议；数字带平滑动画，波动时会出现「追赶」现象，属正常表现。
1.3 曲线区按端口叠加显示最近一段时间的功率曲线，可切换时间范围；点数与平滑方式在「设置 → 进阶配置 → 性能与曲线」调整。
1.4 「已充满」判定：先出现 >5 W 充电，随后功率 ≤0.5 W 连续保持 120 秒，且距最近一次高功率不超过 10 分钟；插着本就满电的设备开机时显示「充电器在位 · 未充电」。
1.5 状态页与端口控制页都会建图；切页、挂起恢复后曲线自动续上，不需要手动刷新。

## 2. 端口控制

2.1 逐口开关：C口1、C口2、C口3、USB-A 各自独立控制，点一次即下发并回读确认。
2.2 协议开关：在支持的端口上切换快充协议族，切换后端口会重新协商，读数刷新约需 1–2 秒。
2.3 倒计时：按分钟设定自动关闭时间，倒计时结束自动关端口；刷新页面不会清除已设定的倒计时。
2.4 「全部关闭」需二次确认，避免误操作导致正在充电的设备断电。
2.5 每张端口卡常驻近 3 分钟功率曲线；空载时保留网格与「无数据」占位，同档位下充电与空载的卡片等高。

## 3. 充电记录

3.1 会话列表按时间倒序展示每次插拔区间，含端口、协议、设备归属、断开原因、时长、充入电量、峰值功率。
3.2 可按时间范围、端口、设备筛选；双击单条会话查看曲线、端口、异常计数与结束原因。
3.3 会话明细中的均压、均流、峰均比、常用口、时段与协议，由该会话的采样点与会话记录统计得到。
3.4 记录保留天数在「设置 → 服务与数据」设置，超期数据按天自动清理。
3.5 列表与明细共用同一份会话数据；改归属、合并、撤销后返回列表即刷新，不需要重启。
3.6 协议列显示 PD / PPS / QC / UFCS / 5V 短码，鼠标悬停看全称；未握手、空闲或空值统一显示「—」，明细页记「未知协议」，不做推断与猜测。协议仅用于展示与人工判断，不参与模型训练。

## 4. 自动化

4.1 无充电自动关端口：端口电流持续低于阈值达设定时长后自动关闭；USB-A 默认豁免，可在「充电限制与保护」调整。判定时长可调，默认 10 分钟。
4.2 A 口小电流自动保持：设备历史会话 ≥3 条、A 口占比 ≥60%、A 口平均功率 <15 W 时触发，把 USB-A 切到小电流模式并保持设定时长（30–240 分钟），到期回默认策略。
4.3 阈值规则：为各端口设置功率下限 / 上限，越界时按规则告警或记录，全零表示不启用该端口。
4.4 通知渠道：充电开始、充电结束、功率告警三类通知可分别开关；「测试通知」用于确认系统通知权限。
4.5 定时控制：为指定端口添加定时任务（时间 + 动作），到点执行；任务列表常驻，可逐条删除。
4.6 每次触发与结束都写入本机日志，可在「设置 → 服务与数据」查看或导出。

## 5. 设置 · 连接设置

5.1 填写充电器的蓝牙地址（MAC）、Token 与蓝牙密钥，点「连接设备」验证，验证通过后点「保存蓝牙配置」持久化。
5.2 扫描超时决定蓝牙扫描等待时长；设备不在附近时会超时失败，可重试。
5.3 「快速接入」说明卡给出获取蓝牙地址与接入巴法云的分步操作，按步骤执行即可。
5.4 状态行只显示短状态词（蓝牙：已连接 / 未连接 / 正在搜索；巴法云：已连接 / 未连接 / 未启用）；服务器地址、失败原因等细节放在悬停提示里，鼠标停在状态词上即可查看。
5.5 MQTT 默认关闭；未填写 broker 信息时不发起任何外连。

## 6. 设置 · 模式与显示

6.1 充电模式（场景模式）：AI模式、数码生态、单口模式、均衡模式四选一，切换即时下发。
6.2 屏幕与显示：设置息屏时间（1 分钟 / 5 分钟 / 10 分钟 / 30 分钟 / 常亮）。
6.3 设备设置：设备语言、空闲息屏、屏幕方向锁、USB-A 小电流，四项同一套切换控件。
6.4 USB-A 小电流启用后，A 口以小电流输出，适合蓝牙耳机、手环等小功率设备。
6.5 外观：主题配色、强调色、动画与特效强度、减少动效，作用于本机界面，不影响充电器。

## 7. 设置 · 充电限制与保护

7.1 各 C 口最大充电时长：达到设定时长自动关闭该口，单位为分钟，0 表示不限制。
7.2 C口3 与 USB-A 的保护通道按机型能力显示，未启用的输入框为置灰状态。
7.3 智能保护：低功率阈值与持续时长组合判断，命中后按策略关闭端口。
7.4 充电与保护：过温阈值、过功率阈值、无充电自动关端口（含「无充电关端口延时」分钟数）、抖动合并秒数；即时生效项保存即下发，「下次分析」项从下一轮统计开始生效。
7.5 保存后即时生效，并在「自动化」页留下记录。

## 8. 设置 · 服务与数据

8.1 服务端口、日志级别、记录保留天数：修改后需保存，部分项重启服务后生效。
8.2 开机自启、每日定时重启与重启时间：随系统与本地服务生效。
8.3 数据导出与记录存储路径：导出为压缩包，路径可自定义；卸载不会自动删除历史库。

## 9. 设置 · 端口统计

9.1 按端口汇总累计充入电量、会话数、平均功率与使用时长。
9.2 统计口径与「充电记录」一致，按会话结束时间归集。

## 10. 设置 · 进阶配置

10.1 设备识别：灵敏度、形态匹配阈值、中心更新策略、候选新设备最小条数、人工作业区间约束、管理分组、设备分组上限。
10.2 性能与曲线：性能模式、实验性功能、端口轮询频率、图表点数、曲线平滑。
10.3 所有开关即时生效；少数需重新加载的项会在该项右侧标注时机。
10.4 底部保留「恢复默认」「保存并应用」与「查看说明与协议」；鼠标在项目上停留 3 秒可看该项说明。
10.5 设备分组上限可在此直接修改（范围 3–30，默认 12）：离开输入框即保存生效，下一次「重新分组」按新上限执行；右侧实时显示「已用 N（固定 X · 自建 Y）」，与分组页标题旁的上限徽标同一口径。非法值（空、越界）不会写入，会恢复为已保存值并在底部状态行提示。
10.6 「管理分组」直接进入设备分组页，不需要另开窗口。

## 11. 小源（AI 助手）

11.1 入口在左侧导航最下方。页内分「对话」「Agent 搭建」「智能分析」「AI 配置」「数据与隐私」五个子页。
11.2 对话可解读充电日报与异常、解释掉速 / 过热 / 断开原因、回答端口与功率问题。
11.3 固定说法直接生成操作卡片（如「今天充电概况」「关闭 C1」「全部关闭」）；单口开关可一键撤销，全部关闭需二次确认。
11.4 「智能分析」离线可算：设备识别、断开原因分布、电压体检、单设备充电习惯与建议；底部动作区进入设备列表、AI 诊断结论、按曲线看分箱与断开规则。
11.5 「AI 复核」给出分箱建议，只做建议不改数据；点「一键采纳」或「采纳所选」后立即落库，并写入审计记录。
11.6 「数据与隐私」决定哪些统计可进入上下文；「AI 配置」管理模型、端点与调用记录。
11.7 能力边界：不能发短信、打电话、主动推送通知，也不能修改设置项；这类请求会明确告知不支持。
11.8 未配置 Key、断网、超时或限流时，对话页显示失败原因并保留问题，可点「重新生成」；本地规则分析不受影响。

## 12. 分组与分箱

12.1 设备按充电曲线形态自动分箱，箱数上限在分组页标题旁常驻显示（上限 / 已用，并区分固定组与自建组）；上限可在「进阶配置 → 设备识别 → 设备分组上限」调整，改完即时生效。
12.2 「按曲线看分箱」按曲线形态聚类查看分箱结果，可对照形态调整灵敏度与阈值。
12.3 固定组不会被「重新分组」改写名称或删改成员；模型只能往固定组新增成员。普通组可并入固定组、并入其它普通组或新建普通组。
12.4 重新分组的主体是「未归箱 + 非固定组」：明显偏离固定组特征的记录进「偏离项」，判不了的进「无法判定」，不散落在未归箱。
12.5 组内会话可单条或批量迁移，迁移与撤销都写入审计记录；「当前分组」列表点选、切换、刷新都保持原滚动位置，滚轮照常可用。
12.6 组内会话行按窗口宽度自适应（字号不变，避免省略）：最小窗口（995×760）用两行行式，首行「冲入电量（Wh）·端口·峰值功率·协议短码」，次行「时长·平均电压（V）·平均电流（A）」；1280 及以上回到单行七字段。数值缺失时显示「—」占位，悬停可看完整文本。
12.7 维度约束默认不预置：固定组、普通组、新建组一视同仁，要不要加由用户点「约束」自行设置；「恢复自动」会清空该组约束，清空后该组不再按区间判定。已有数据只清理「系统预置且用户没改过」的部分，用户手设的值保留。
12.8 改归属、合并、新建组、删除组之后，分组页与智能分析同步刷新，不需要重启。
12.9 组卡片第三行末尾显示该组「主协议 + 占比」（如「主协议 PD 3.0 62%」），按组内会话协议统计；无有效协议时显示「未知」。
12.10 「协议」是可选约束维度：在维度约束弹窗中勾选并填写短码（如 PD,PPS）后才参与过滤；不勾选不生效、不预置，也不进入模型特征向量。
12.11 协议的价值只在辅助人工校正与分组判断：可用于核对候选行、解释组间差异；学习模型仍只使用数值特征（功率、电量、时长、均压均流、时段、端口、峰均比与曲线形态）。
